# Mai Tycoon

방송용 원본 띵타이쿤의 농사 흐름을 재현하는 Paper 플러그인 초기 버전입니다.
현재는 기본 마을에서 재배 → 수확 → NPC 판매 → 씨앗 구매로 이어지는 흐름을 실행할 수 있습니다.
원본 전체 재현은 아직 완료되지 않았습니다. 확인된 규칙과 미확인 항목은 [개발 계획](docs/PLAN.md)을 참고하세요.

이번 UI·건축 상점·커스텀 작물·시세 변경 사항은 [요청 및 구현 기록](docs/ui-refresh/REQUESTS-2026-10-31.md)에 정리했습니다.

## 환경 및 빌드

- Minecraft Java Edition / Paper **1.21.11**, Java **21**
- Maven 3.9 이상. 이 작업 공간에는 `.tools/`에 macOS ARM64 개발 도구를 준비했습니다.
- `./build.sh` 실행 → `target/mai-tycoon-<현재 버전>.jar`
- 다른 컴퓨터에서는 Java 21과 Maven 설치 후 `mvn verify`로 빌드합니다.

## 설치 및 플레이

1. Paper 1.21.11 서버의 `plugins/`에 JAR을 넣고 서버를 시작합니다. 기존 월드는 변경되지 않습니다.
   마을을 지으려면 콘솔에서 `tycoon village build confirm`을 입력합니다. 스폰 주변 지형이 평탄화되므로 월드를 먼저 백업하세요.
2. 서바이벌 모드에서 `/tycoon starter`로 테스트용 괭이·밀 씨앗·빵을 받습니다.
3. 남동쪽 공용 농장이나 남서쪽 특수 작물 밭에서 작물을 심고 거둡니다. 기본 마인크래프트 성장·뼛가루·수확 규칙을 사용합니다.
4. 광장 북쪽 **작물 상인**을 우클릭해 작물을 팝니다. 위쪽 탭으로 분류를 고르고, 호퍼로 거래 수량을 바꿉니다. 좌클릭은 선택 수량을 바로 팔고, 우클릭(해당 작물 전부)과 모두 판매는 합계를 확인하는 화면을 거칩니다.
5. **씨앗 상인**을 우클릭해 씨앗과 도구를 삽니다. 좌클릭은 선택 수량, 우클릭은 한 묶음입니다.
   건축 자재는 광장 남서쪽 **건축 자재 상인**에게 구매합니다.
6. 광장 서쪽 **도감 사서**에게 아이템을 제출해 도감을 채웁니다. 30개를 등록하면 땅 구매 이용권을 받습니다.
7. 광장 동쪽 **토지 관리인**의 지도에서 빈 청크를 우클릭해 땅을 삽니다.

| 명령어 | 설명 |
|---|---|
| `/tycoon info` | 보유 골드 확인 |
| `/tycoon price` | 현재 시세 보기 |
| `/tycoon village` | 마을 광장으로 이동 |
| `/tycoon dex` | 수집 도감 열기 |
| `/tycoon land` | 땅 지도와 농장 관리 열기 |
| `/tycoon land member add\|remove <이름>` | 내 땅의 작업자 관리 |
| `/tycoon give <이름> gold\|zcoin <수량>` | (관리자, 콘솔 가능) 골드, 즈코인 지급 |
| `/tycoon village build confirm` | (관리자, 콘솔 가능) 마을 생성 또는 재건축. 지형이 바뀌고 농장 작물이 초기화됩니다 |
| `/tycoon journal` | (관리자, 콘솔 가능) 중단된 거래 기록 보기, `resolve <번호>`로 처리 |
| `/tycoon buildshop` / `seedshop` / `cropshop` | 관리자 전용 상점 열기. 일반 유저는 NPC를 우클릭합니다 |
| `/tycoon market next` | (관리자, 콘솔 가능) 시세 즉시 갱신 |

## 시세와 작물

- 기본 작물 18종과 커스텀 작물 12종을 판매할 수 있습니다. 기본 목록과 기준가는 `plugins/MaiTycoon/config.yml`의 `crops`에서 수정하고 재시작합니다.
- 판매가는 10분마다 기준가의 50~180%에서 독립 무작위 추첨합니다. 품목별 서버 판매량이 256개 누적될 때마다 다음 회차 하락 압력 10%(최대 60%)를 적용하며, 과잉 판매 품목은 최저가를 지키면서 직전 가격보다 내려갑니다. `swing`은 호환용 필드입니다.
- 커스텀 작물은 `custom-crops.crops`에서 설정합니다. 기존 6종에 양파·무·가지·오이·파프리카·블루베리가 추가되었고, 32px 수확물·씨앗 봉투·3단계 성장 텍스처를 제공합니다.
- 시세·회차별 판매량·다음 갱신 시각은 `market.yml`에 저장되어 재시작해도 유지됩니다. 변동 시 전체 채팅으로 가장 많이 오르고 내린 작물을 알립니다.
- 씨앗 구매가는 고정이며 `seeds`에서 수정합니다. 판매도 되는 품목(당근 등)의 구매가가 최고 시세 이하이면 되팔기로 골드를 찍어낼 수 있어 서버가 플러그인을 켜지 않습니다.
- 모든 가격은 개발용 임시값이며 실제 원본 시세가 아닙니다.
- 이름·설명·커스텀 데이터가 있는 작물과 보조 손 아이템은 판매하지 않습니다.
- 데이터는 `plugins/MaiTycoon/players/<UUID>.yml`에 즉시 저장합니다. 서버는 정품 인증 모드 사용을 전제로 합니다.

## 관리자

`maitycoon.admin`(OP 기본 보유)은 마을과 땅 보호를 무시하고, 크리에이티브에서도 거래하며, 이용권과 10청크 한도 없이 땅을 사고, 재화를 지급하고, 모든 관리 명령을 쓸 수 있습니다.

## 상점

작물 상인, 씨앗 상인, 건축 자재 상인, 가구 상인이 광장에 있습니다. 건축 자재는 목재, 석재, 장식, 색상(양털, 콘크리트, 테라코타, 색유리 각 16색) 탭이고, 가구는 침대, 조명, 수납, 장식 탭입니다. 품목은 `building-shop`, `furniture-shop`에서 수정합니다. 새 품목의 이름 칸은 `ShopLayout`에도 추가해야 합니다.

## 마을

- 광장(분수) 북쪽에 상점 2곳, 동서 도로변에 마을회관·민가·공동 창고, 남동쪽에 공용 농장 4곳, 남서쪽에 사탕수수·선인장·네더 사마귀·버섯·다시마·열대 작물 밭이 있습니다.
- 마을 안에서는 농장 구역의 작물만 심고 거둘 수 있습니다. 관리자는 제한을 받지 않습니다. 폭발, 화재, 자연 적대 몹 스폰도 막습니다.
- 기본 월드 시드는 `607115319713086458`입니다. 스폰이 평원이고 주변 800블록의 약 84%가 육지입니다. 시작 스크립트가 처음 만드는 `server.properties`에 들어갑니다.
- 마을은 중심에서 100블록까지입니다. 건물 구역(44블록) 바깥 56블록이 확장 예정 범위입니다(`village.reserve`). 이 안의 땅은 살 수 없고, 기본 설정에서는 일반 유저가 블록을 부수거나 놓을 수 없습니다(`village.protect-reserve`). 몹은 스폰됩니다.
- 위치는 `plugins/MaiTycoon/village.yml`에 저장됩니다. 바닐라 스폰 보호는 끄고 위 구역 규칙으로 대체합니다.

## 상점 화면과 리소스팩

- 접속할 때 상점 화면용 리소스팩을 권합니다. 받으면 전용 화면이, 거절하거나 실패하면 같은 칸 배치의 기본 아이템 GUI가 표시됩니다. 조작은 동일합니다.
- 팩은 플러그인이 `pack.port`(기본 25580)로 제공합니다. 다른 사람이 접속하는 서버는 `pack.host`를 공인 주소로 바꾸고 포트를 여세요.
- 칸 배치는 `ShopLayout` 한 곳에서 정의합니다. 화면을 바꾸려면 빌드 후 `java -cp target/classes tools/GeneratePack.java`로 `pack.zip`을 다시 만듭니다.
- 배경의 한글은 나눔고딕(SIL OFL)으로 그렸습니다. 생성에는 폰트 설치가 필요하고, 배포물에는 이미지만 들어갑니다.
- 전용 화면은 자체 디자인이며 원본 띵타이쿤 화면이 아닙니다.

## 거래 안전

- 모두 판매와 우클릭 판매는 대상, 수량, 합계를 확인한 뒤 진행합니다. 확인 순간 시세나 인벤토리가 바뀌었으면 팔지 않고 새 합계를 보여 줍니다.
- 모든 거래는 시작 전에 `plugins/MaiTycoon/journal/`에 기록되고, 잔액과 인벤토리를 저장한 뒤 지워집니다.
- 서버가 거래 도중 멈추면 기록이 남습니다. 어느 쪽까지 반영됐는지 알 수 없으므로 자동으로 다시 지급하지 않고, 그 플레이어의 거래만 멈춥니다. 관리자가 `/tycoon journal`로 확인해 바로잡은 뒤 `resolve`합니다.

## 수집 도감

- 웅크리기 키를 빠르게 두 번 누르거나 웅크린 채 손 바꾸기 키(기본 `Shift+F`)로 어디서든 엽니다(살 수 있는 땅 위에서는 구매 화면이 먼저 열리고 거기에 도감 버튼이 있습니다). 도감 사서나 `/tycoon dex`로도 열 수 있습니다.
- 농사(커스텀 작물 포함), 채광, 사냥, 바다·요리에 더해 게임에서 얻을 수 있는 나머지 아이템이 블록, 음식, 기타 페이지에 자동 등록됩니다(`dex.all-items`). 스폰 알과 명령 블록처럼 서바이벌에서 얻을 수 없는 것은 제외합니다.
- 항목이나 인벤토리의 아이템을 클릭하면 1개를 제출해 등록합니다. 제출한 아이템은 사라집니다.
- 달성 보상은 10/20/30/50/72/100/150/200/250/300개 구간에 있습니다. 20개에 생활 램프, 30개에 땅 구매 이용권을 줍니다(`dex.rewards`).
- 즈코인은 골드와 별개의 재화로, `/tycoon info`와 도감 화면에서 확인합니다. 아직 쓸 곳은 없습니다.
- 원본의 10/20/30/50개 구간, 코인 수량, 30개 이용권은 따랐습니다. 등록 방식, 72종 구성, 골드 금액은 개발용입니다.

## 청크 땅

- 마을이 있는 월드에서 청크 단위로 삽니다. 1청크는 16×16블록이고 1인당 최대 10개입니다. 이용권은 계정에 등록되고 구매할 때 소모되지 않습니다.
- 살 수 있는 땅에 서면 화면 위쪽에 가격이 표시됩니다. 웅크리기 키를 빠르게 두 번 누르거나(웅크린 채 손 바꾸기 키도 가능) 채팅의 `[이 땅 구매하기]`를 누르면 구매 확인 화면이 열리고, 토지 관리인의 땅 지도에서도 살 수 있습니다.
- 바닐라는 게임 화면 위 표시를 클릭할 수 없어 단축키와 채팅 링크로 대신합니다. 표시 위치는 창 크기에 따라 조금 달라지고, 리소스팩이 없으면 가운데에 나옵니다.
- 가격은 5,000 골드에서 시작해 땅이 늘 때마다 2,500 골드씩 오릅니다(`config.yml`의 `land`). 마을과 경사면 구역은 살 수 없습니다.
- 내 땅에서는 작물을 제외한 모든 것이 보호됩니다. 다른 사람은 블록, 상자, 문, 양동이, 도구를 쓸 수 없지만 작물은 거둘 수 있습니다(원본의 서리 규칙).
- 서버는 웅크리기 상태만 알 수 있어 키를 바꾼 플레이어는 자기 웅크리기 키를 눌러야 합니다. 화면 안내에는 각자의 키가 표시됩니다.
- 역할: 소유자는 전부, 작업자는 수확·파종·경작만, 방문자는 작물 수확만 가능합니다. 작업자는 `/tycoon land member add|remove <이름>`으로 관리하며 내 땅 전체에 적용됩니다(작업자는 프로젝트 제안 기능).
- 피스톤, 물·용암, 호퍼, 디스펜서, 불, 나무 성장, 폭발, 몹, 액자·갑옷 거치대가 경계를 넘어 땅을 건드리는 것도 막습니다.
- 땅 되팔기는 아직 없습니다. 땅은 `plugins/MaiTycoon/lands.yml`에 월드 UUID 기준으로 저장되며, 예전 파일은 자동으로 옮겨집니다.

## 커스텀 작물

- 배추, 토마토, 옥수수, 딸기, 포도, 파인애플 6종입니다. 씨앗 상인의 특산 탭에서 씨앗을 사서 경작지에 우클릭으로 심습니다.
- 성장은 실제 시간 기준이고 뼛가루는 쓸 수 없습니다(`custom-crops.bone-meal`). 다 자라면 수확물과 씨앗이 나오고, 덜 자랐을 때 베면 씨앗만 돌아옵니다.
- 한 청크에 100개까지 심을 수 있습니다(원본 표기). 품목과 수치는 `config.yml`의 `custom-crops`에서 수정합니다. 새 품목의 그림과 이름 칸은 `ShopLayout`, `tools/GeneratePack.java`에도 추가해야 합니다.
- 공용 농장 3·4번에 전시용 작물이 미리 심겨 있습니다. 리소스팩이 없으면 씨앗과 수확물은 종이, 작물은 풀 모양으로 보입니다.
- 도감에는 아직 없습니다.

## 미니맵

- 리소스팩을 받은 플레이어의 화면 오른쪽 위에 북쪽이 위인 지도가 표시됩니다. 한 칸이 8블록이고 사방 약 100블록을 보여 줍니다.
- 지도는 서버의 실제 지형을 읽으므로 모두 같은 지형을 봅니다. 본인은 흰 점, 다른 플레이어는 노란 점입니다.
- 모드 없이 글자로 그리는 방식이라 위치가 창 크기에 따라 조금 달라지고, 서버가 로드하지 않은 지역은 어둡게 나옵니다. 탐험 기록은 쌓이지 않습니다.

## 생활 램프

- 수집 도감 20개를 달성하면 생활 램프를 받습니다. 괭이를 손에 들고 토지 관리인 메뉴의 생활 램프 버튼이나 `/tycoon lamp`로 적용합니다.
- 옵션은 무작위입니다. 추가 작물·씨앗 20~50% 확률로 1~3개, 추가 뼛가루 10~50% 확률로 1~2개입니다(`config.yml`의 `lamp`). 수치는 2차 자료 기재를 따랐습니다.
- 이미 옵션이 있는 괭이에 쓰면 새 옵션으로 바뀝니다. 부여 절차, 교체 규칙, 수량을 적용 때 정하는 방식은 원본 미확인이라 제안 구현입니다.
- 밀, 당근, 감자, 비트를 다 자란 뒤 직접 수확할 때만 적용됩니다. 덜 자란 작물, 취소된 수확, 크리에이티브 모드, 커스텀 작물은 제외합니다.
- 관리자는 `/tycoon lamp give <이름> <개수>`로 지급할 수 있습니다.

## 자동 심기

- 토지 관리인 메뉴의 자동 심기 버튼 또는 `/tycoon autoplant`에서 켜고 끕니다. 즈코인 1개로 1000회를 살 수 있습니다(`config.yml`의 `auto-plant`).
- 밀, 당근, 감자, 비트를 다 자란 뒤 직접 수확하면 같은 작물을 다시 심습니다. 내 땅, 작업자로 등록된 땅, 공용 농장, 주인 없는 땅에서 동작합니다.
- 심기에 성공할 때만 씨앗 1개와 1회를 씁니다. 씨앗은 수확 전에 보관 칸에서 꺼내므로 방금 떨어진 씨앗은 쓰이지 않고, 씨앗이 없으면 수확만 됩니다.
- 커스텀 작물은 아직 지원하지 않습니다. 횟수와 소모 방식은 원본 미확인이라 제안 구현이고, 원본의 도감 200개 히든 상점 제한은 없습니다.
- 관리자는 `/tycoon autoplant give <이름> <횟수>`로 지급할 수 있습니다.

## 트랙터 (실험)

- 기본으로 꺼져 있습니다. `config.yml`의 `tractor.enabled`를 true로 바꾸고 재시작하면 자동 심기 메뉴에서 즈코인 200개로 살 수 있습니다.
- 괭이를 들고 웅크린 채 다 자란 작물을 우클릭하면 사방 4칸을 틱당 2칸씩 수확합니다. 내 땅, 작업자 땅, 공용 농장만 수확합니다.
- 자동 심기가 켜져 있으면 같은 규칙으로 다시 심습니다. 생활 램프 보너스는 적용되지 않습니다.
- 로그아웃, 도구 교체, 멀리 이동, 청크 언로드 때 멈춥니다. 연료와 내구도 소모는 없습니다. 범위와 속도는 원본 미확인 임시값입니다.

## 서리와 발자국

- 방문자가 남의 땅에서 작물을 거두면(열매 우클릭 포함) 발자국이 남습니다. 취소된 수확, 소유자·작업자·관리자의 수확은 기록하지 않습니다.
- 소유자는 토지 관리인 → 농장 관리에서 발자국을 우클릭해 신고합니다. 발자국마다 한 번만, `land.report-days`(기본 7일, 원본 미확인) 안에만 가능합니다.
- 신고하면 행위자 이름이 소유자에게 공개되고 행위자에게 알림이 갑니다. 경찰, 수배, 처벌은 아직 없습니다. 기록은 `plugins/MaiTycoon/footprints.yml`에 저장됩니다.

## 검증 상태 및 한계

- Maven 빌드 및 시세·통화 단위 테스트 제공.
- 별도 테스트 서버에서 마을 자동 생성, 블록 배치, 재시작 후 NPC 1명씩 유지, 시세 저장을 확인했습니다.
- 같은 서버에서 가짜 플레이어로 실제 클릭·블록 이벤트를 보내 상점 두 화면, 판매 확인, 도감, 땅 구매, 보호 규칙을 확인했습니다(자동 검증 243개).
- 새 서버에서 확인 없이는 마을이 지어지지 않는 것을 확인했습니다.
- 실제 강제 종료와 디스크 쓰기 실패 상황은 아직 시험하지 않았습니다. 중단 기록의 거래 정지는 시험했습니다.
- 실제 클라이언트의 전용 화면 표시는 아래 체크리스트로 확인해야 합니다.
- 직업, 원본 전체 작물 목록은 아직 미구현입니다. 공용 농장은 누구나 거둘 수 있습니다.
- 원본 UI는 공개 자료가 없어 재현하지 않았습니다. 현재 UI는 바닐라 GUI로 만든 자체 구성입니다.
- 농사 레벨/판매 경험치는 원본 근거가 없어 제외했습니다.
- YAML과 플레이어 인벤토리는 별도 저장입니다. 거래 저널은 중단을 감지해 멈출 뿐 자동으로 되돌리지 않습니다.
- 파일 저장은 메인 스레드에서 수행하는 소규모 개발 서버용 구현입니다.

## 인게임 확인 체크리스트

- 리소스팩을 받았을 때와 거절했을 때 모두 상점이 정상 표시되고 숫자가 칸에 맞는지 확인(GUI 크기 2/3/4).
- 작물 상인·씨앗 상인 우클릭으로 각 GUI가 열리고, 주민 거래창이 뜨지 않는지 확인.
- 공용 농장 1·2의 다 자란 밀·당근을 거둬 판매하고 수량 × 표시 단가만큼 골드가 늘어나는지 확인.
- 씨앗을 사면 골드가 줄고, 골드나 인벤토리 공간이 부족하면 거절되는지 확인.
- 커스텀 이름 작물, 보조 손 아이템이 판매되지 않는지 확인.
- GUI에서 shift 클릭, 숫자키, 더블클릭, 드래그로 상점 아이템을 꺼낼 수 없는지 확인.
- 농장 밖 블록 파괴·설치, 농지 밟기, 밭 밖 괭이질이 막히는지 확인.
- 도감 사서·토지 관리인 우클릭으로 도감과 땅 지도가 열리는지 확인.
- 도감 제출, 땅 구매, 청크 경계 표시가 동작하는지 확인.
- 다른 플레이어가 내 땅에서 블록과 상자는 못 쓰고 작물은 거둘 수 있는지, 발자국이 남고 신고되는지 확인.
- 재접속·정상 서버 재시작 후 골드, 시세, NPC, 도감, 땅이 유지되는지 확인.
- 크리에이티브/관전자에서는 보급·거래가 거절되는지 확인.
