# Mai Tycoon

방송용 원본 띵타이쿤의 농사 흐름을 재현하는 Paper 플러그인 초기 버전입니다.
현재는 기본 마을에서 재배 → 수확 → NPC 판매 → 씨앗 구매로 이어지는 흐름을 실행할 수 있습니다.
원본 전체 재현은 아직 완료되지 않았습니다. 확인된 규칙과 미확인 항목은 [개발 계획](docs/PLAN.md)을 참고하세요.

## 환경 및 빌드

- Minecraft Java Edition / Paper **1.21.11**, Java **21**
- Maven 3.9 이상. 이 작업 공간에는 `.tools/`에 macOS ARM64 개발 도구를 준비했습니다.
- `./build.sh` 실행 → `target/mai-tycoon-0.3.0.jar`
- 다른 컴퓨터에서는 Java 21과 Maven 설치 후 `mvn verify`로 빌드합니다.

## 설치 및 플레이

1. Paper 1.21.11 서버의 `plugins/`에 JAR을 넣고 서버를 시작합니다. 기존 월드는 변경되지 않습니다.
   마을을 지으려면 콘솔에서 `tycoon village build confirm`을 입력합니다. 스폰 주변 지형이 평탄화되므로 월드를 먼저 백업하세요.
2. 서바이벌 모드에서 `/tycoon starter`로 테스트용 괭이·밀 씨앗·빵을 받습니다.
3. 남동쪽 공용 농장이나 남서쪽 특수 작물 밭에서 작물을 심고 거둡니다. 기본 마인크래프트 성장·뼛가루·수확 규칙을 사용합니다.
4. 광장 북쪽 **작물 상인**을 우클릭해 작물을 팝니다. 위쪽 탭으로 분류를 고르고, 호퍼로 거래 수량을 바꿉니다. 좌클릭은 선택 수량을 바로 팔고, 우클릭(해당 작물 전부)과 모두 판매는 합계를 확인하는 화면을 거칩니다.
5. **씨앗 상인**을 우클릭해 씨앗과 도구를 삽니다. 좌클릭은 선택 수량, 우클릭은 한 묶음입니다.
6. 광장 서쪽 **도감 사서**에게 아이템을 제출해 도감을 채웁니다. 30개를 등록하면 땅 구매 이용권을 받습니다.
7. 광장 동쪽 **토지 관리인**의 지도에서 빈 청크를 우클릭해 땅을 삽니다.

| 명령어 | 설명 |
|---|---|
| `/tycoon info` | 보유 YD 확인 |
| `/tycoon price` | 현재 시세 보기 |
| `/tycoon village` | 마을 광장으로 이동 |
| `/tycoon dex` | 수집 도감 열기 |
| `/tycoon land` | 땅 지도 열기 |
| `/tycoon village build confirm` | (관리자, 콘솔 가능) 마을 생성 또는 재건축. 지형이 바뀌고 농장 작물이 초기화됩니다 |
| `/tycoon journal` | (관리자, 콘솔 가능) 중단된 거래 기록 보기, `resolve <번호>`로 처리 |
| `/tycoon market next` | (관리자, 콘솔 가능) 시세 즉시 갱신 |

## 시세와 작물

- 작물 18종을 판매할 수 있습니다. 목록, 기준가, 변동 폭은 `plugins/MaiTycoon/config.yml`의 `crops`에서 수정하고 재시작합니다.
- 판매가는 10분마다 작물별로 기준가의 50~180% 안에서 움직이며, 기준가로 되돌아가려는 성질이 있습니다. 변동 폭(`swing`)이 큰 작물일수록 크게 흔들립니다.
- 시세는 `market.yml`에 저장되어 재시작해도 유지됩니다. 변동 시 전체 채팅으로 가장 많이 오르고 내린 작물을 알립니다.
- 씨앗 구매가는 고정이며 `seeds`에서 수정합니다. 판매도 되는 품목(당근 등)의 구매가가 최고 시세 이하이면 되팔기로 YD를 찍어낼 수 있어 서버가 플러그인을 켜지 않습니다.
- 모든 가격은 개발용 임시값이며 실제 원본 시세가 아닙니다.
- 이름·설명·커스텀 데이터가 있는 작물과 보조 손 아이템은 판매하지 않습니다.
- 데이터는 `plugins/MaiTycoon/players/<UUID>.yml`에 즉시 저장합니다. 서버는 정품 인증 모드 사용을 전제로 합니다.

## 마을

- 광장(분수) 북쪽에 상점 2곳, 동서 도로변에 마을회관·민가·공동 창고, 남동쪽에 공용 농장 4곳, 남서쪽에 사탕수수·선인장·네더 사마귀·버섯·다시마·열대 작물 밭이 있습니다.
- 마을 안에서는 농장 구역의 작물만 심고 거둘 수 있습니다. 관리자는 제한을 받지 않습니다. 폭발, 화재, 자연 적대 몹 스폰도 막습니다.
- 위치는 `plugins/MaiTycoon/village.yml`에 저장됩니다. 바닐라 스폰 보호는 끄고 위 구역 규칙으로 대체합니다.

## 상점 화면과 리소스팩

- 접속할 때 상점 화면용 리소스팩을 권합니다. 받으면 전용 화면이, 거절하거나 실패하면 같은 칸 배치의 기본 아이템 GUI가 표시됩니다. 조작은 동일합니다.
- 팩은 플러그인이 `pack.port`(기본 25580)로 제공합니다. 다른 사람이 접속하는 서버는 `pack.host`를 공인 주소로 바꾸고 포트를 여세요.
- 칸 배치는 `ShopLayout` 한 곳에서 정의합니다. 화면을 바꾸려면 빌드 후 `java -cp target/classes tools/GeneratePack.java`로 `pack.zip`을 다시 만듭니다.
- 배경의 한글은 나눔고딕(SIL OFL)으로 그렸습니다. 생성에는 폰트 설치가 필요하고, 배포물에는 이미지만 들어갑니다.
- 전용 화면은 자체 디자인이며 원본 띵타이쿤 화면이 아닙니다.

## 거래 안전

- 모두 판매와 우클릭 판매는 대상, 수량, 합계를 확인한 뒤 진행합니다. 확인 순간 시세나 인벤토리가 바뀌었으면 팔지 않고 새 합계를 보여 줍니다.
- 모든 거래는 시작 전에 `plugins/MaiTycoon/journal/`에 기록되고, 잔액과 인벤토리를 저장한 뒤 지워집니다.
- 서버가 거래 도중 멈추면 기록이 남습니다. 어느 쪽까지 반영됐는지 알 수 없으므로 자동으로 다시 지급하지 않고, 그 플레이어의 거래만 멈춥니다. 관리자가 `/tycoon journal`로 확인해 바로잡은 뒤 `resolve`합니다.

## 수집 도감

- 농사, 채광, 사냥, 바다·요리 4페이지 72종입니다. 항목은 `config.yml`의 `dex.pages`에서 수정합니다.
- 항목이나 인벤토리의 아이템을 클릭하면 1개를 제출해 등록합니다. 제출한 아이템은 사라집니다.
- 달성 보상은 10개 500 YD, 20개 1,500 YD, 30개 3,000 YD와 땅 구매 이용권, 50개 10,000 YD, 72개 30,000 YD입니다.
- 원본의 10/20/30/50개 구간과 30개 이용권은 따랐습니다. 등록 방식, 72종 구성, YD 금액은 개발용입니다.

## 청크 땅

- 마을이 있는 월드에서 청크 단위로 사며 1인당 최대 9개입니다. 이용권은 계정에 등록되고 구매할 때 소모되지 않습니다.
- 가격은 5,000 YD에서 시작해 땅이 늘 때마다 2,500 YD씩 오릅니다(`config.yml`의 `land`). 마을과 경사면 구역은 살 수 없습니다.
- 내 땅에서는 작물을 제외한 모든 것이 보호됩니다. 다른 사람은 블록, 상자, 문, 양동이, 도구를 쓸 수 없지만 작물은 거둘 수 있습니다(원본의 서리 규칙).
- 어둠의 발자국, 땅 되팔기, 친구 권한은 아직 없습니다. 땅은 `plugins/MaiTycoon/lands.yml`에 저장됩니다.

## 검증 상태 및 한계

- Maven 빌드 및 시세·통화 단위 테스트 제공.
- 별도 테스트 서버에서 마을 자동 생성, 블록 배치, 재시작 후 NPC 1명씩 유지, 시세 저장을 확인했습니다.
- 같은 서버에서 가짜 플레이어로 실제 클릭·블록 이벤트를 보내 상점 두 화면, 판매 확인, 도감, 땅 구매, 보호 규칙을 확인했습니다(자동 검증 110개).
- 새 서버에서 확인 없이는 마을이 지어지지 않는 것을 확인했습니다.
- 실제 강제 종료와 디스크 쓰기 실패 상황은 아직 시험하지 않았습니다. 중단 기록의 거래 정지는 시험했습니다.
- 실제 클라이언트의 전용 화면 표시는 아래 체크리스트로 확인해야 합니다.
- 램프, 직업, 원본 전체 작물 목록은 아직 미구현입니다. 공용 농장은 누구나 거둘 수 있습니다.
- 원본 UI는 공개 자료가 없어 재현하지 않았습니다. 현재 UI는 바닐라 GUI로 만든 자체 구성입니다.
- 농사 레벨/판매 경험치는 원본 근거가 없어 제외했습니다.
- YAML과 플레이어 인벤토리는 별도 저장입니다. 거래 저널은 중단을 감지해 멈출 뿐 자동으로 되돌리지 않습니다.
- 파일 저장은 메인 스레드에서 수행하는 소규모 개발 서버용 구현입니다.

## 인게임 확인 체크리스트

- 리소스팩을 받았을 때와 거절했을 때 모두 상점이 정상 표시되고 숫자가 칸에 맞는지 확인(GUI 크기 2/3/4).
- 작물 상인·씨앗 상인 우클릭으로 각 GUI가 열리고, 주민 거래창이 뜨지 않는지 확인.
- 공용 농장 1·2의 다 자란 밀·당근을 거둬 판매하고 수량 × 표시 단가만큼 YD가 늘어나는지 확인.
- 씨앗을 사면 YD가 줄고, YD나 인벤토리 공간이 부족하면 거절되는지 확인.
- 커스텀 이름 작물, 보조 손 아이템이 판매되지 않는지 확인.
- GUI에서 shift 클릭, 숫자키, 더블클릭, 드래그로 상점 아이템을 꺼낼 수 없는지 확인.
- 농장 밖 블록 파괴·설치, 농지 밟기, 밭 밖 괭이질이 막히는지 확인.
- 도감 사서·토지 관리인 우클릭으로 도감과 땅 지도가 열리는지 확인.
- 도감 제출, 땅 구매, 청크 경계 표시가 동작하는지 확인.
- 다른 플레이어가 내 땅에서 블록과 상자는 못 쓰고 작물은 거둘 수 있는지 확인.
- 재접속·정상 서버 재시작 후 YD, 시세, NPC, 도감, 땅이 유지되는지 확인.
- 크리에이티브/관전자에서는 보급·거래가 거절되는지 확인.

## 간편 배포와 로컬 실행

- 공유 파일: `dist/mai-tycoon-starter-0.3.0.zip`
- 패키지 재생성: `./scripts/package.sh` (빌드/테스트 후 ZIP 생성)
- 자세한 안내: [설치안내](distribution/설치안내.md)
- 이 컴퓨터의 서버: `server/start.command` 실행. 접속 주소 `127.0.0.1:25565`.
- 참가자는 플러그인을 설치하지 않습니다. 서버 운영자만 JAR을 설치합니다.
- 배포 ZIP에는 월드, 사용자 데이터, EULA 동의, 계정 정보가 포함되지 않습니다.
