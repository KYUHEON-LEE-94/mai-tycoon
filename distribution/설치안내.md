# 마이 타이쿤 빠른 시작

## 친구 서버에 참가하는 사람
플러그인이나 모드를 설치할 필요가 없습니다. 정품 Minecraft Java Edition 1.21.11로
멀티플레이 → 직접 연결 → 운영자가 알려준 주소로 접속하세요.
Bedrock Edition 및 다른 버전은 이 패키지의 지원 대상이 아닙니다.

## 이미 Paper 서버가 있는 운영자
1. 서버를 정상 종료하고 기존 월드와 plugins 폴더를 백업합니다.
2. Paper 1.21.11 / Java 21인지 확인합니다.
3. 이 ZIP의 plugins/mai-tycoon-0.1.0.jar를 서버 plugins 폴더에 복사합니다.
   이전 MaiTycoon JAR은 별도 폴더로 옮겨 같은 플러그인이 두 번 로드되지 않게 합니다.
4. **기존 월드라면 서버를 켜기 전에** `plugins/MaiTycoon/config.yml`의 `village.auto-build`를 false로 바꾸세요.
   기본값은 첫 실행 때 스폰 주변 약 110칸 사방을 평탄화해 마을을 짓습니다. 나중에 `/tycoon village build`로 지을 수 있습니다.
5. 서버를 다시 시작합니다. 별도 의존 플러그인이나 리소스팩은 없습니다.
6. 0.2.0에서 올린다면 `plugins/MaiTycoon/config.yml`을 지우고 다시 생성하세요. 설정 형식이 바뀌어 예전 파일로는 플러그인이 켜지지 않습니다.

## 처음 로컬 서버를 만드는 운영자
1. ZIP을 원하는 **새 폴더**에 완전히 압축 해제합니다.
2. Java 21을 설치합니다: https://adoptium.net/temurin/releases/?version=21
   Windows는 설치 후 터미널/실행 창을 다시 열어 주세요.
3. macOS: start.command 더블클릭. Linux: 터미널에서 bash start.command 실행.
   Windows: start.bat 더블클릭 (PowerShell 실행 정책이 차단하면 관리자 정책에 맞는 허용 또는 수동 실행을 사용하세요).
4. 공식 Paper 파일을 내려받고 SHA-256을 확인합니다. 최초 실행은 인터넷이 필요합니다.
5. 화면에 표시된 Minecraft EULA를 읽고 동의할 때만 AGREE를 입력합니다.
6. 콘솔에 Done이 나오면 Minecraft 런처에서 Java Edition → 설치 설정 → 새 설치 설정 → release 1.21.11을 선택해 실행합니다.
7. 멀티플레이 → 직접 연결 → 127.0.0.1:25565 로 접속합니다.
8. 첫 실행 때 스폰에 마을이 자동으로 지어집니다. /tycoon starter로 보급품을 받고, 공용 농장에서 농사를 지은 뒤
   광장 북쪽의 작물 상인에게 팔고 씨앗 상인에게 씨앗을 삽니다. /tycoon price로 시세, /tycoon info로 YD를 확인합니다.
   도감 사서에게 아이템을 제출해 도감을 채우고, 30개를 등록하면 토지 관리인에게서 청크 땅을 살 수 있습니다.
9. 서버를 끌 때 콘솔에 stop을 입력합니다. 월드·plugins 폴더는 다음 실행에도 유지합니다.

시작 파일은 기존 eula.txt와 server.properties를 덮어쓰지 않습니다.
기본 메모리 상한은 2GB입니다. 필요하면 시작 파일의 -Xmx2G를 조정하세요.

## 다른 사람과 함께 플레이
기본 설정은 본인 PC에서만 접속 가능한 127.0.0.1입니다.
실제 공동 플레이에는 Paper 1.21.11을 지원하는 서버 호스팅에 플러그인 JAR을
업로드하는 방법이 간단합니다. 제공받은 서버 주소를 친구에게 공유하면 됩니다.
직접 호스팅할 때는 server-ip, 방화벽, 네트워크 구성을 별도로 설정해야 합니다.
이 패키지는 공유기나 방화벽을 자동 변경하지 않습니다.

## 자주 겪는 문제
- 연결 거부: 서버 콘솔의 Done 확인, 서버가 켜져 있는지 확인.
- 버전 불일치: Java Edition 1.21.11 프로필로 실행.
- Java 없음/UnsupportedClassVersionError: Java 21 설치 및 JAVA_HOME 확인.
- 명령어 없음: plugins에 JAR을 넣었는지, 콘솔에 MaiTycoon 활성화 오류가 없는지 확인.
- macOS 실행 권한 없음: 폴더에서 터미널을 열고 bash start.command 실행.
- 포트 사용 중: 기존 서버를 정상 종료하거나 server.properties의 server-port를 바꾸고 해당 포트로 접속.

현재 개발용 초기 버전입니다. 가격은 임시값이며 농장 소유권/램프 기능은 미구현입니다.
서버 강제 종료 시 통화와 인벤토리 간 거래 복구는 아직 보장하지 않습니다.
