# 방송용 띵타이쿤 농사 재현 계획

기준: 2024년 방송용 원본 띵타이쿤. 띵타이쿤 온라인과 구분합니다.
조사일: 2026-10-30. 현재 자료는 2차 정리 자료이므로 영상/운영 안내 원문으로 추가 검증이 필요합니다.

## 구현 단계

1. **초기 농사 루프 (완료)**: 바닐라 경작·성장·수확, 판매, 10분 시세, 골드 저장.
1.5. **기본 마을과 NPC 상점 (완료)**: 스폰 마을, 작물·씨앗 상인 NPC, 작물 18종, 작물별 시세 변동, 마을 보호.
2. **농사 터전 (현재)**: 수집 도감, 땅 구매 이용권, 청크 땅 구매·보호 구현 완료. 남은 일은 어둠의 발자국과 서리 신고, 땅 권한, 마을/야생 월드 분리.
   세부 설계와 티켓은 [farming-design](farming-design/README.md)을 따릅니다. D02 안전 설치, D03 공통 배치, D04 판매 확인·거래 저널, D05 땅 권한·간접 보호, D06 서리 기록·신고, D07 도감·화폐 보상 모델을 적용했고, D08 생활 램프, D09 자동 심기도 적용했습니다. 다음은 기본 비활성 실험인 D10 트랙터입니다.
3. **도구 성장**: 괭이 생활 램프 옵션과 추가 수확. 실제 옵션 부여 방식과 중복 적용 규칙 확인 후 구현.
4. **상점 재현**: 원본 농사 상점의 품목·가격표·매입 단위·NPC 동선 반영. 현재 NPC 상점의 임시 값을 원본 자료로 교체.
5. **운영 준비**: 인벤토리/통화 간 거래 복구, 저장 부하 개선, 다중 사용자 및 실제 서버 통합 검증.

## 원본으로 확정하지 않은 개발 편의 기능

- `starter` 보급품, 현재 GUI 배치, 상인 NPC 2명 구성, 마을 배치와 건물.
- 작물 18종 목록, 기준 가격, 씨앗 구매가, 50~180% 범위의 작물별 랜덤워크 시세.
- 마을 보호 규칙과 공용 농장. 원본은 마을 월드/야생 월드 분리, 청크 단위 땅 구매(최대 9개)로 정리되어 있어 2단계에서 다시 맞춥니다.
- 현재 Paper 버전은 개발 타깃이며 원본 서버 버전을 재현한 것이 아닙니다.

## 현재 구현의 개발용 가정

- 도감 등록은 아이템 1개 제출 방식, 항목은 4페이지 72종, 보상은 띵코인 대신 골드입니다.
- 땅 구매 이용권은 계정에 등록되어 소모되지 않으며, 땅 가격은 5,000 골드부터 2,500 골드씩 오릅니다.
- 상점 UI는 사용자가 제공한 참고 화면의 구성을 자체 그래픽으로 만든 것입니다. 출처가 확인되지 않아 방송 원본 화면이라고 단정하지 않으며, 리소스팩이 없으면 기본 GUI로 동작합니다.
- 커스텀 작물은 배추·파인애플·포도만 원본 언급이 있고, 토마토·옥수수·딸기와 성장 시간, 가격, 수확량은 개발용 값입니다. 성장은 바닐라 틱이 아니라 실제 시간 기준입니다.
- NPC 외형, 마을 건물, 상점 건물은 자체 디자인입니다.
- 원본의 띵코인은 게임 안에서 즈코인이라고 부릅니다. 골드와 별도 지갑이며 아직 쓸 곳은 없습니다. 조사 문서의 띵코인은 원본 기록이라 그대로 둡니다.
- 도감 보상의 즈코인 수량은 원본 10/20/30/50개 구간을 따르고, 골드 금액은 임시로 유지합니다. 생활 램프, 펫 티켓 등 다른 보상은 아직 없습니다.
- 자동 심기는 성공한 재심기만 씨앗 1개와 1회를 쓰는 제안 구현입니다. 즈코인 1개에 1000회, 히든 상점 조건 없음은 임시 결정입니다.
- 땅 한도는 요청에 따라 10청크입니다(원본 표기는 9개). 마을 범위 100블록과 그 안의 보호는 프로젝트 결정입니다.
- 월드는 스폰 주변 육지 비율을 측정해 고른 시드를 씁니다. 원본 월드 지형을 재현한 것이 아닙니다.
- 미니맵은 원본 근거가 없는 요청 기능입니다. 보스바 글자로 그리며, 탐험 공유가 필요해지면 클라이언트 모드 검토 대상입니다.
- 클라이언트 모드는 쓰지 않습니다. 필요해지면 서버 기능은 그대로 두고 선택 설치로 추가하는 방향을 검토합니다.
- 원본의 화폐 YD는 게임 안에서 골드라고 부릅니다. 저장 데이터의 coins는 그대로입니다. 조사 문서의 YD는 원본 기록이라 그대로 둡니다.
- 작물값은 청크 가격에 맞춰 5배로 올렸습니다. 씨앗 겸 작물과 뼛가루도 함께 올렸고, 커스텀 작물의 뼛가루는 즉시 이익이 나서 기본으로 막습니다.
- 작업자 역할은 프로젝트 제안이고, 작물 파괴는 덜 자란 경우에도 발자국으로 기록합니다. 신고 기간 7일은 임시값입니다.
- 판매 확인 화면, 도감, 땅 지도는 아직 전용 그래픽이 없습니다.

## 미확인 사항

원본 UI 화면과 리소스팩 사용 여부, 도감 등록 방식과 전체 항목, 땅 가격과 이용권 소모 여부, 마을의 실제 배치, 농사 상점 NPC 유무, 정확한 판매 작물 전체 목록, 원본 시세 상하한과 분포, 상점 클릭 방식,
땅 획득 절차의 상세 규칙, 램프 획득/장착 방식 및 수확 판정.
확인 전에는 가공·전용 씨앗·물주기·품질 등급·농사 레벨 같은 별도 규칙을 추가하지 않습니다.
자료가 확보되면 가정과 구현을 함께 수정합니다.

## 2026-10-31 사용자 요청으로 확정한 확장

원본 미확인 사항과 별개로 사용자가 요청한 커스텀 작물 12종, 건축 자재 상점, 독립 무작위 시세와 판매량 하락 보정, 관리자 전용 상점 명령어를 구현했습니다.
원본을 재현한 수치로 간주하지 않으며, 전체 규칙·UI 참고 기준·후속 제안·검증은 [요청 및 구현 기록](ui-refresh/REQUESTS-2026-10-31.md)을 기준으로 합니다.
