# 클라이언트 호환표

2026-11-02 · P0 지도 미리보기 배포. 정식 필수 운영 전환 전 단계다.

| 항목 | 고정 버전 |
|---|---|

| 게임/서버 Java 기준 | 21 (클라이언트 바이트코드 release 21) |
| 클라이언트 빌드 JDK | 25 (Loom 1.19.3 요구) |
| Fabric Loader | 0.20.1 |

서버 0.22.0에는 모드 통신 기능이 없다. 기존 서버에 모드만 설치해도 M 키 지도가 작동하는 것은 아니다.
서버 리소스팩은 기존 서버 제공 팩을 사용한다. 미리보기 ZIP에는 리소스팩, Fabric API, Minecraft, 계정 정보, 서버 주소를 넣지 않는다.

## 검증 범위

- 기존 개발 실행 로그: Mac 개발 클라이언트가 localhost:25590에 접속해 protocol 1.0 연결 성공, 지도 캡처 저장 후 종료.
- 이어받은 작업: 서버 Maven 테스트, 클라이언트 Gradle 테스트 및 배포 JAR 빌드, ZIP 구성과 체크섬 검사.
- 이번 보강 후 새 클라이언트를 기존 localhost:25590 시험 서버에 다시 연결해 handshake, 지도 수신, 실제 화면 캡처를 확인했다(JDK 25 실행). 서버 보강분은 Maven 검증만 완료했으며 해당 시험 서버에는 교체하지 않았다.
- 미검증: 정품 계정 접속, 클라이언트 Java 21 실행, Windows 설치, 여러 사용자 동시 접속, 새 서버 빌드의 필수 모드 제한 경로.
- 램프·상점·토지 거래 전용 모드 화면은 아직 구현되지 않았다. 지도는 열람 전용이다.

## 운영 전환

`client.required: true`가 최종 운영 정책이다. 참가자 설치와 실제 접속 검증을 마친 다음 켠다.
현재 기본값 `false`는 전환 준비용이며, 정식 선택 설치 정책을 뜻하지 않는다.
서버와 모드 업데이트는 함께 안내하고, 문제 발생 시 백업한 플러그인과 설정을 복원한다.

## 0.2.0 (2026-11-02)

- Mai Tycoon 메뉴(서버 글꼴로 그린 화면)에서 한 칸씩 밝아지던 hover를 버튼 전체 단위로 바꿨다. 같은 아이템이 이웃한 칸을 한 버튼으로 본다. 빈 배경 칸은 밝아지지 않는다. 일반 상자와 플레이어 인벤토리는 그대로다.
- 개발 클라이언트로 램프 상점의 구매 버튼 위에 포인터를 둔 화면을 찍어 확인했다. 통신 규격은 1.0 그대로다.

## 간편 설치 패키지 (2026-11-04)

Windows 배치/PowerShell 및 Mac command 파일을 동봉한다. 참가자에게 Python이나 빌드 도구를 요구하지 않는다. Fabric Installer 1.1.2를 공식 저장소에서 내려받아 같은 버전 조합을 설치한다. Windows 실제 PC 검수는 남아 있다. 사용/복구 절차는 `distribution/client/INSTALL.md`, 구현은 `EASY-INSTALL-2026-11-04.md` 참고.

## 0.3.0 (2026-11-04)

- 전체 지도가 화면 전체를 쓰고, 한 칸이 1청크에서 8블록으로 바뀌어 4배 세밀해졌다(규격 1.1의 `cellBlocks`). 기본 배율 x6, 범위 1024블록.
- 내 위치와 다른 유저 표시를 키우고 테두리·깜박이는 고리·이름표 배경을 넣었다.
- 서버 0.24.0은 0.2.0 클라이언트에 1.0 형식(청크 단위)을 그대로 보낸다.
