# 농사 기능 설계

아래는 RESEARCH.md의 근거를 토대로 만든 **프로젝트 구현 제안**이다. 명시하지 않은 수치와 동작을 원본 규칙으로 간주하지 않는다.

## 플레이 루프

야생에서 재료 확보 → 도감 등록 → 땅 획득 조건 충족 → 마을에서 필지 선택 → 경작·파종 → 성장·수확 → 시세 확인 → 판매 또는 보관 → 종자/도구 구매 → 농장 확장.
생활 램프와 자동화는 이 루프에 생산 편의를 더한다. 초반의 수작업을 건너뛰는 무료 자동화는 주지 않는다.
도감 30개를 농사 18종만으로 달성할 수 없다는 점을 튜토리얼에 분명히 안내하고 야생 안내로 연결한다.

## 기능별 계약

### F01 경작과 성장

- 바닐라 식재·빛·성장·물·뼛가루 규칙을 사용한다. 서버 전체 성장 속도를 몰래 변경하지 않는다.
- CropDefinition에 판매 아이템과 실제 재배 블록, 수확 방식, 종자 재료를 구분한다.
- 1차 추가 효과 지원은 밀·당근·감자·비트 4종부터. 판매 18종 지원과 자동화 지원 범위는 별개다.
- 열매 우클릭, 코코아 방향, 네더와트 토양, 수박 열매/줄기, 2블록 작물, 수직 다중 블록은 각각 어댑터와 테스트를 추가한 뒤 활성화한다.
- 크리에이티브 수확은 일반 바닐라 동작을 존중하되 경제 보너스와 자동화 보상은 지급하지 않는다.

### F02 수확 파이프라인

`권한 확인 → 수확 가능 상태 판정 → 기본 드롭 산정 → 램프 판정 → 재심기 가능 여부 → 실제 수확/드롭/차감 → 결과 기록`
- 취소된 이벤트에는 보너스·주문서 차감·발자국을 남기지 않는다.
- 성숙 작물 직접 수확만 1차 보너스 대상으로 한다. 미성숙 파괴, 물·피스톤·폭발은 추가 보상 대상에서 제외하는 제안이다.
- 이벤트 종류가 겹쳐도 block+tick+actor+action 단위로 수확을 한 번만 처리한다.
- 자연 드롭을 직접 계산한다면 기본 드롭을 억제하고 전체 결과를 한 번 지급한다. 기본 드롭에 추가 드롭을 더하는 방식과 혼용 금지.
- 추가 수확 아이템을 가상의 재수확 이벤트로 재귀 처리하지 않는다.
- 수확물은 기본 월드 드롭을 유지하고 자동 인벤토리 흡수는 별도 기능으로 추가하지 않는다.

### F03 시세·구매·판매

- 현재 시장 모델을 유지하고 가격, 다음 갱신 시각, 이전 대비 변동을 표시한다. 원본 미확인 수치는 config에 남긴다.
- 판매 목록에서 단일 수량 거래는 즉시, ‘모두 판매’는 대상·수량·합계 확인 화면을 거친다.
- 제안: 작물별 ‘남길 수량’을 기본 0으로 제공. 당근/감자 등을 다음 파종에 남길 수 있다. 전체 판매 여부를 선택한 카테고리와 혼동하지 않게 표시한다.
- preview는 quote ID와 시장 revision을 가진다. 확인 시 인벤토리·가격·권한을 재검증한다. 바뀌었으면 새 견적만 표시하고 사용자가 다시 확인해야 거래한다.
- 저장 실패 시 아이템 이동 금지. ‘잔액 저장 후 인벤토리 제거’만으로는 강제 종료 복구를 보장하지 못한다.
- 서버 메인 스레드에서 플레이어별 거래 락을 두고 거래 ID/전후 지갑/인벤토리 스냅샷을 durable journal에 기록한다. ambiguous crash는 자동 중복 지급하지 말고 복구 대기 상태와 관리자 도구로 처리한다. 장기적으로 통화·보관품을 같은 DB 트랜잭션에 넣는 구조도 검토한다.
- 이름/커스텀 아이템·장비·보조 손은 판매 제외. 대량 구매는 부분 지급 없이 공간과 잔액을 먼저 확인한다.
- 구매 가능한 작물을 즉시 되팔아 이익이 나지 않는지 설정 로딩 시 검증. 조합·분해·뼛가루 변환 경로까지 별도 경제 검수.

### F04 땅과 서리

- 월드 UUID+청크 좌표를 식별자로 사용. 소유자, 멤버 역할, 생성 시각, 설정 버전을 저장한다.
- 원본의 서리를 재현하려면 ‘남의 작물 수확 허용’과 ‘행위 기록’을 함께 제공해야 한다.
- 권한 표: 소유자=건설/수확/저장고/신고, 작업자=수확/재파종(새 제안), 방문자=이동/허용된 작물 서리, 관리자=명시적 관리 권한.
- 방문자의 상자 열기·경작지 파괴·물/용암 붓기·피스톤·호퍼 경계 이동은 별도 보호 대상이다. Berry 우클릭도 서리 판정에 포함한다.
- Footprint: UUID, actor UUID, owner UUID, world UUID, position, cause, createdAt, reportedAt, reporter UUID. 같은 사건 신고는 한 번만 반영.
- 신고 화면은 신고 가능 발자국만 표시. 소유권 변경·중복 클릭·자기 발자국·이미 처리된 건은 서버가 재검증한다.
- 발자국 표시 기간과 신고 유효 기간은 설정으로 분리하고 원본 미확인이라고 표시한다. 경찰·체포·법원은 농사 MVP 밖의 연계 인터페이스로 둔다.

### F05 도감·재화

- 현재 YD 보상 대체는 임시다. YD, 띵코인, 직업 코인을 이름만 바꿔 하나의 지갑으로 처리하지 않는다.
- RewardDefinition에 요구 개수, 화폐 종류/수량, 지급 아이템, 권한 해금, claim ID를 둔다.
- 등록 시 아이템 소비 여부는 원본 확인 전 현재 동작 유지. 화면에서 ‘1개 제출’이라고 명시한다.
- 이미 등록한 항목은 소비하지 않는다. 보상 수령은 재접속·동시 클릭에도 1회만 처리한다.
- 도감 확장 때 72개 기준 보상을 삭제하거나 기존 진행을 초기화하지 않는다. legacy 보상 ID를 보존하고 신규 구간으로 마이그레이션한다.

### F06 생활 램프

- 도구 PDC에 option ID, probability, amount, schemaVersion 저장. UI lore는 표시이며 판정 근거가 아니다.
- 확률과 수량은 검증된 범위와 서버 설정으로 결정한다. 시안의 예시는 테스트 데이터다.
- 옵션 교체는 기존 옵션/새 옵션/소모품을 보여주는 확인 화면이 필요하다. 옵션 중첩 규칙은 미확인 상태이므로 활성화를 서두르지 않는다.
- Fortune·Silk Touch·다중 작물·자동 심기·트랙터의 조합 테스트 후 지원 범위를 늘린다.

### F07 자동 심기와 트랙터

- 자동 심기 제안: 본인/작업 권한 필지에서 성숙 작물 수동 수확 후 동일 작물 재심기. 유효 토양·빈 자리·씨앗·횟수가 있을 때만 씨앗 1개와 1회를 소비한다. 씨앗이 없으면 수확은 유지하고 재심기만 생략한다.
- 씨앗은 수확 직전 보관 인벤토리에서 예약해 차감한다. 새로 떨어진 씨앗을 자동으로 흡수하지 않는다. 당근·감자는 종자 겸 작물로 처리한다.
- 횟수 0이면 기능 비활성화. 잔여 횟수는 액션바에 필요할 때만 표시한다.
- 트랙터는 먼저 권한/수확 어댑터를 재사용하는 제한 범위 일괄 작업으로 검증한다. 범위·속도·시각 모델은 원본 확인 전 config 실험값, 기본 비활성화.
- 청크 로드 강요 금지, 틱당 처리 상한, 소유지 밖 즉시 정지, 작업 중 로그아웃/도구 교체/재시작 중단 처리. 미수확 대상에 씨앗/횟수 차감 금지.
- 트랙터 수확에서 램프를 다시 적용할지는 확정 전 off. 연료·내구도·자동 판매는 근거 없이 추가하지 않는다.
