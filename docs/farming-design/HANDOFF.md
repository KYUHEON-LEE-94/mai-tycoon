## 테스트 매트릭스

1. 상점: 0개/1개/부분 스택/여러 스택/이름 있는 아이템/보조 손. 전부 판매는 예고한 수량·합계만 처리.
2. 구매: 정확한 잔액, 1 YD 부족, 빈칸 0, 일부 스택만 빈 공간, 괭이 최대 스택 1.
3. 입력: shift/숫자키/double click/Q/드래그/닫기. 메뉴 아이템 복사 및 이동 불가.
4. 시세: 조회 직후 갱신, 확인 직전 갱신, 거래 후 재접속. 화면과 지급 금액 일치.
5. 내구성: 디스크 쓰기 실패/잔액 저장 직후 종료/인벤토리 변경 직후 종료. 복구 불명확 시 거래 중지와 관리자 확인이 가능할 것.
6. 도감: 같은 항목 연속 등록, 같은 보상 연속 클릭, 저장 실패, 기존 프로필 로딩, 신규 항목 추가 후 진행 보존.
7. 땅: 음수 청크/월드 경계/같은 필지 두 명 구매/최대치/이용권 미보유/다른 월드.
8. 서리: own/member/visitor/admin × break/right-click/물/피스톤/폭발. 취소된 수확은 발자국 0.
9. 재심기: 성숙도별/씨앗 0·1/횟수 0·1/바뀐 토양/이미 심김/타인 땅. 실패 시 씨앗·횟수 감소 0.
10. 램프: 확률 0/100 테스트 override, 실제 설정 범위, Fortune, 도구 바꾸기, 체인 파괴, 자동화로 보너스 중복 없음.
11. UI: 팩 거절·재다운로드·오래된 팩, 한글/영문 클라이언트, 긴 이름/큰 금액, GUI scale 2/3/4.
12. 설치: 빈 서버와 기존 서버 각각. 기존 월드/플레이어 데이터가 보존되고 운영자만 JAR을 설치하면 참가 가능.

## 필요한 자원과 미완료

- 서버/Paper/Java/빌드 스크립트는 기존 준비물을 재사용. 새 플러그인 의존성 구매/설치 필요 없음.
- 폰트: 프로젝트에 배포 가능한 한글 폰트와 라이선스 고정. 당장은 기본 게임 폰트로 시작.
- 시각 자산: assets.csv. 생성기 원본을 유지하고 설계 문서만 보고 pack.zip을 덮어쓰지 말 것.
- 원본 자료: 상점 화면, 램프 적용 장면, 자동 심기·트랙터 시연이 가장 가치가 높음. 확보 실패가 기본 거래 UI 개발을 막지는 않음.
- 이번 작업에서는 운영 서버 재시작, 월드 생성, 플러그인 설치, 클로드 메시지 전송을 하지 않음.
