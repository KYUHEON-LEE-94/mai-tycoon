## 이번 설계의 결정

- 기본 경작은 바닐라를 유지한다. 원본에서 확인되지 않은 전용 물주기·스태미나·품질·농사 레벨을 추가하지 않는다.
- 현재 18종 상점, YD, 도감, 땅 기능을 기반으로 다듬는다. 원본 전체 품목과 동일하다는 표시는 하지 않는다.
- 기본 재현 범위: 생활 경제 + 땅 + 서리. 확장 범위: 생활 램프 + 자동 심기 + 트랙터.
- 실제 원본 UI 이미지를 확보하지 못했다. 시안은 프로젝트의 나무·양피지 방향을 발전시킨 **자체 제안**이다.
- 안정적인 바닐라 GUI를 반드시 제공하고 리소스팩은 선택적 시각 향상으로 취급한다.
- 실서버 배포 전 거래 복구와 기존 월드 보존을 먼저 해결한다.

## 현재 가장 중요한 차이

| 항목 | 코드 관찰 | 인계 방향 |
|---|---|---|
| 상점 | NPC, 수량 선택, 시세, 18종 판매 있음 | 거래 확인, 잔여 종자 보관, 가격 변경 처리 |
| 도감 | 72종, YD 보상, 이용권 boolean | YD와 별개 화폐 모델, 보상 규칙 설정 분리 |
| 땅 | 청크 소유권, 작물 파괴 예외 있음 | 서리 기록과 신고, 멤버·재배 권한의 일관성 |
| 자동화 | 읽은 코드에 주문서·트랙터 없음 | 수동 수확 파이프라인 완성 후 확장 |
| UI | Shop 36품목 바닐라 배치 / GeneratePack 20품목 배치 | 슬롯·좌표 공통 계약부터 확정 |
| 설치 | config에 village.auto-build: true | 기존 월드 자동 평탄화 방지, 새 월드 opt-in |

## 준비 상태

조사표, 기능 명세, 슬롯 명세, 색/타이포 토큰, 자산 제작 목록, 개발 티켓, 수용 테스트를 준비했다.
최종 PNG/모델/폰트는 제작하지 않았다. 원본 화면 검증 전 자산을 확정하지 않고 진행 중인 GeneratePack 작업과 충돌을 피한다.
자료 확인을 막는 요소는 RESEARCH.md에 기록했다. 사용자가 답하지 않아도 개발 제안에 명시된 기본값으로 다음 작업을 진행할 수 있다.
