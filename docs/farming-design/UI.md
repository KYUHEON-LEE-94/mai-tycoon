# 화면과 디자인 명세

원본 화면을 직접 검증하지 못했으므로 아래는 Mai Tycoon 자체 디자인 제안이다.
현재 GeneratePack.java의 나무 프레임·양피지·실물 아이템 방향을 이어간다. 웹 시안은 동작 설명용이며 실제 슬롯과 크기는 이 문서가 기준이다.

## 시각 규칙

- 프레임: 짙은 목재 #4A3020, 양각 #6B4A30. 본문: 양피지 #F0E4C8, 아이템 칸 #FFF8E8, 본문 글자 #3A2818.
- 주요 행동: 잎색 #3F6C42, 흰 글자. 금액: 어두운 바탕에서 #FFD860, 밝은 바탕에서는 #765414.
- 경고: #9C3B2E + 문장. 상승/하락은 ▲/▼와 숫자를 함께 사용해 색만으로 구분하지 않는다.
- 외곽과 슬롯은 1 GUI px 단위에 정렬. 둥근 모서리는 작게, 나무결·그림자는 낮은 대비로 제한한다.
- 기본 아이템 아이콘을 사용하고 카테고리만 별도 아이콘을 제작한다. 작물마다 큰 커스텀 그림을 만들지 않는다.
- 한글 본문은 Minecraft 기본 폰트 우선. 제목·배경 글자를 이미지에 넣을 때 폰트 파일/라이선스/빌드 버전을 고정한다. macOS 설치 폰트에만 의존하지 않는다.
- GUI scale 2/3/4, 1280×720 및 1920×1080에서 테스트. 숫자를 잘라 맞추지 않는다. 큰 잔액은 제목을 짧게 표시하고 툴팁에는 전체 값을 보여준다.

## 공통 54슬롯 계약 (리소스팩 버전 제안)

Shop 코드와 GeneratePack이 서로 다른 배치를 사용 중이므로 한 LayoutDefinition에서 아래 데이터를 공유하도록 변경한다.
이 설계는 기존 36품목보다 큰 가격 표시 영역을 확보하는 **20품목안**이다. 현재 배치를 조용히 섞지 말고 렌더러 버전으로 나눈다.

- 9열×6행, 슬롯=행×9+열, 좌상단 0. GUI 논리 배경 176×128.
- 아이템 원점 x=8, y=18, 슬롯 간격 18 (현 생성기 값). 클라이언트 제목/배경 이동 오프셋은 인게임 검증 후 고정.
- 행 0~4의 열 0: 카테고리 0,9,18,27,36.
- 행 0~4의 열 1/3/5/7: 상품 아이콘 20개.
- 해당 열 오른쪽 2/4/6/8: 가격 글자 영역. **짝수 열 클릭도 왼쪽 상품과 동일하게 매핑**한다.
- 하단: 45 이전, 46~48 수량 선택, 49~52 주요 행동, 53 다음. 넓은 버튼의 모든 슬롯에 같은 handler를 연결한다.
- 제목 영역 잔액·갱신 정보는 표시 전용. 숫자 글리프 범위 부족 시 툴팁으로 보완한다.
- 카테고리가 5개를 넘으면 명시적 ‘더 보기’ 화면을 사용하거나 페이지 구성을 제한한다. 묵시적으로 탭을 누락하지 않는다.
- 폰트 배경 위 플레이어 인벤토리/툴팁 영역을 가리지 않는다. 세로 배치 오프셋은 창 크기에 따라 실제 마인크래프트가 결정한다.

## 화면 목록과 행동

| ID | 화면 | 표시/조작 | 오류·빈 상태 |
|---|---|---|---|
| U01 | 농산물 판매 | 품목, 개당 YD, 변동, 보유 수량, 다음 시세. 상품 좌클릭 지정 수량, 우클릭 해당 품목 판매 견적 | 보유 0이면 거래 불가, 커스텀 제외 개수 안내 |
| U02 | 씨앗·농기구 구매 | 씨앗/모종/농기구 구분, 수량, 단가, 총액. 좌클릭 지정 수량 구매 | 잔액/공간 부족이면 원인과 필요한 수량 표시 |
| U03 | 판매 확인 | 목록 요약, 종자 제외량, 합계, 현재/예상 잔액, 확인/취소 | 시세 또는 인벤토리 변경 시 재견적, 자동 실행 없음 |
| U04 | 도감 | 등록됨/제출 가능/미보유 3상태, 누적/다음 보상, 보상 수령 | 중복 등록 비활성화, 제출 소모량 명시 |
| U05 | 필지 선택 | 주변 청크 5×5, 현재 위치, 소유/타인/판매/마을 표시 | 월드 불일치·이용권 없음·상한·선점 원인 분리 |
| U06 | 땅 구매 확인 | 월드/청크/범위, 금액, 보유 한도, 이용권 처리, 확인/취소 | 위치 이동 후에도 선택했던 필지를 표시하고 재검증 |
| U07 | 농장 관리 | 멤버/경계 표시/발자국 목록/허용 작업 | 권한이 없으면 조회 범위 제한 |
| U08 | 램프 적용 | 대상 괭이, 현재 옵션, 적용 규칙, 소비량, 확인 | 대상 오류·재료 부족. 임의 슬롯에 아이템을 끌어넣지 않음 |
| U09 | 자동 심기 상태 | 켜짐/꺼짐, 횟수, 씨앗 부족 안내 | 수확 성공과 재심기 실패를 구분 |
| U10 | 서리 신고 | 위치/발견 시각/처리 상태, 신고 확인 | 중복·만료·권한 오류는 소비 없이 반환 |

U03/U06/U08 확인 화면: 54칸. 13 대상, 20~24 요약, 30~32 확인, 39~41 취소. Escape는 취소와 동일.
U05 지도: 행1~5 열2~6의 25칸을 사용. 중심 31이 현재 청크, 북쪽은 위. 0 정보, 8 닫기, 45 뒤로, 53 경계 미리보기. 선택은 U06으로 이동하며 즉시 구매하지 않는다.
U04는 기존 DexMenu 흐름 유지. 농사/채광/사냥/바다·요리 분류를 자동화 스킨에 맞추려고 바꾸지 않는다.

## 상태 전이

상점 열기 → 품목/카테고리 선택 → 수량 변경 → 일괄 판매 미리보기 → 확인 → 성공 영수증 → 상점 복귀.
확인 화면 중 시세 갱신 → 새 합계 및 ‘가격이 바뀌었습니다’ 표시 → 재확인.
종료/로그아웃/다른 GUI 열기 → preview 폐기. 확인 버튼 연타 → 첫 거래만 수행.

## 실제 메시지 문안

- 성공: `밀 32개를 판매했습니다. +256 YD · 잔액 1,536 YD`
- 시세 갱신: `시세가 바뀌어 합계를 다시 계산했습니다. 금액을 확인해 주세요.`
- 종자 유지: `다음 파종용 감자 16개는 남겨두었습니다.`
- 보관 공간: `씨앗 64개를 넣을 공간이 부족합니다.`
- 서리: `다른 사람의 농작물을 수확했습니다. 발자국이 남았습니다.`
- 재심기 실패: `수확 완료 · 씨앗이 없어 다시 심지 못했습니다.`
- 저장 실패: `거래를 완료하지 못했습니다. 아이템과 잔액을 확인해 주세요.` (복구 상태에 따라 거래 중단)

## 리소스팩 / 설치

- 팩 거절·다운로드 실패·버전 불일치는 기본 아이템 GUI로 돌아간다. 팩을 아직 받지 않은 플레이어에게 사설 글리프를 보내지 않는다.
- 새로운 팩 수락 상태에 맞춰 열린 GUI를 닫았다 재개하거나 안전하게 다시 그린다. 렌더러별 클릭 계약은 동일해야 한다.
- 클라이언트 1.21.11을 고정 타깃으로 검증한다. 현 GeneratePack의 pack_format 값은 추정 승인하지 말고 실제 클라이언트로 확인한다.
- 마을/NPC/상점 타이틀 전체에 하나의 용어집 사용: 농산물 상점, 씨앗·농기구, YD, 띵코인, 땅 구매 이용권, 생활 램프.
- 참가자는 모드 설치 없이 접속. 원격 접속용 팩은 모든 참가자가 접근 가능한 HTTPS 주소·해시·버전을 제공한다.
- 브라우저 시안의 카드·버튼을 웹뷰로 게임에 넣는 방식은 아니다. 인벤토리 슬롯·폰트·아이템으로 변환한다.

## 월드 아트 / 동선 제안

스폰 게시판 → 정면 시장길 → 좌측 농산물 매입/우측 종자 판매 → 뒤쪽 작은 공용 실습밭 → 토지 안내소 → 개인 필지 출구.
최초 동선에서 ‘수확한 것을 어디에 파는지’를 먼저 보이게 한다. 간판은 목적 중심으로 쓰고 NPC 대사는 2문장 안으로 제한한다.
나무 기둥·밝은 회벽·황토 지붕·녹색 천막을 반복하고, 물·작물·길의 경계를 명확히 한다. 각 상점 바닥 재료와 간판 아이콘을 함께 달리한다.
전체 마을 자동 재건축 대신 별도 월드 생성 또는 관리자가 지정한 빈 구역에만 설치한다. 기존 저장된 마을 좌표는 보존한다.
