# 방송용 띵타이쿤 UI 조사와 램프·토지 개선 지침

조사일: 2026-11-01. 대상: **2024년 방송용 원본**. 띵타이쿤 온라인은 제외한다.
목적: 구현 중인 UI를 원본에 가깝게 수정하기 위한 근거와 작업 명세.
적용 상태: 0.18.0에 L01·L02·T01~T03을 구현했다. §7의 인게임 해상도별 캡처는 아직 남아 있다. 화폐 표시는 사용자 지시에 따라 골드를 유지한다.

**토지 지도·구매 확인창의 실제 원본 화면은 이번 조사에서 확보하지 못했다.** 아래 토지 배치는 원본 상점의 시각 언어를 적용한 Mai Tycoon 제안이다. 원본에서 5×5 지도, 우측 상세 패널, F키를 사용했다고 표기하면 안 된다.

원본 위키의 램프 이미지 링크는 503, 연결된 Notion 아카이브는 404로 열리지 않았다. 이미지 파일명만 보고 화면을 복원하지 않았다. 공식 영상의 자막 내보내기는 실패했지만 페이지의 ‘스크립트 표시’로 해당 구간 자막을 확인했다.

## 2. 실제로 본 램프 상점

공식 영상의 **27:20부터 시작하는 램프 설명 구간**에서 다음을 확인했다. 링크는 구간 시작점이며 모든 요소가 그 첫 프레임에 동시에 나오는 것은 아니다.

- 월드/NPC가 뒤로 보이는 짙은 반투명 직사각형 패널. 얇은 밝은 금색 외곽선과 제목 구분선.
- 제목은 좌측 위 `램프 상점`. 큰 일러스트나 나무 장식 없이 정보 중심.
- 상품은 좌측 위 한 장의 가로 카드. 램프 커스텀 아이콘 왼쪽, `생활 도구 전용 램프` 이름 오른쪽.
- 카드의 **파란 구매 버튼**에 가격을 직접 표시. 시연 화면에서 `10,000 YD`와 같은 금액의 구매 채팅 확인. 이는 시연 당시 값이며 현재 프로젝트 가격을 자동으로 바꾸라는 지시가 아니다.
- 구매 툴팁은 `좌클릭 시 1개 구매`, `쉬프트+좌클릭 시 64개 구매`를 안내.
- 아이콘 아래 작은 보유 수량, 패널 하단 중앙 `1/1`. 상품이 하나라고 빈칸 전체를 아이템 슬롯으로 채우지 않음.
- 좌상단 게임 HUD에는 초상화·계좌 잔액·직업이 별도로 표시됨.
- 이어지는 구간은 일반 플레이어 인벤토리와 도구 툴팁을 보여준다. 도구에 붙은 옵션을 툴팁으로 읽을 수 있음. **현재 프로젝트의 ‘대상/현재 능력/보유 램프 + 옵션 목록 + 적용’ 전용 창을 원본 화면이라고 볼 근거는 없다.**

구매 카드와 적용 UX는 분리해서 판단한다. 원본 상점의 카드 구조는 재현할 수 있으나 적용 제스처는 추가 검증 전까지 임의로 ‘원본과 동일’이라고 부르지 않는다.

## 3. 현재 구현과 차이

아래는 조사 시점 소스 읽기 결과다. 인게임 렌더링 검수 결과는 아니며 Claude가 수정 중이므로 구현 직전에 다시 확인한다.

| 연결점 | 현재 관찰 | 개선 방향 |
|---|---|---|
| `tools/GeneratePack.java: lampScreen()` | 전용 어두운 배경 존재. 대상/현재 능력/램프 3상자, 옵션 슬롯 2행, 구매/적용/닫기 3버튼 | 색은 이미 근접. 격자와 동일 비중의 버튼을 줄이고 상점/적용 역할 분리 |
| `src/main/java/kr/maitycoon/Lamps.java` | 현재 옵션·가격·잔액·설명이 주로 아이템 이름과 lore에 있음 | 핵심 비용·보유량·현재 능력은 마우스를 올리지 않아도 읽히게 표시 |
| 같은 파일 | 램프 0개여도 아이콘 스택은 최소 1로 표시하고 lore에 실제 수량 표기 | 화면 숫자를 실제 보유량과 일치. 0개 상태를 별도 표현 |
| `src/main/java/kr/maitycoon/Lands.java` | 9×5 청크 지도와 하단 잔액/자동 심기/소유 땅/램프/이용권/농장/경계 보기 혼재 | 토지 선택과 농장 관리 분리. 선택한 땅의 정보와 행동을 가까이 배치 |
| 같은 파일의 구매 확인 | 54칸 창에 필지 아이콘, 여러 슬롯의 구매/취소 버튼 | 금액·좌표·구매 후 잔액을 읽는 확인 카드 구성 |
| 기존 `docs/farming-design/UI.md` | 목재/양피지, 20품목 중심의 초기 제안 | 이번 사용자 참조와 충돌하는 외형·배치 제안은 폐기. 거래 안전성·fallback 검수는 유지 |

불만의 핵심은 단순 색상이 아니라 **아이템 슬롯들이 화면 구조를 대신하고, 필요한 정보를 hover로 찾아야 한다는 점**이다. 이는 코드와 제공된 현재 화면을 토대로 한 디자인 평가다.

## 4. 공통 외형 — 원본 관찰을 바탕으로 한 제작 기준

- 짙은 차콜 배경, 얇은 금색 선, 밝은 본문, 넉넉한 카드 여백. 양피지·두꺼운 나무틀·모든 칸의 테두리는 사용하지 않는다.
- 제작용 제안 색상: 배경 `#211E1C`, 카드 `#302B29`, 금색 선 `#E9D49C`, 본문 `#F4EBDD`, 보조 `#BDB2A3`, 구매 파랑 `#77B9D5`, 판매 빨강 `#D96666`. **원본에서 측정한 정확한 색상값은 아니다.**
- 구매/판매 버튼은 색과 한글 동사를 함께 표시. 램프 구매와 적용은 다른 행동임을 명확히 한다.
- 헤더: 화면 제목. 본문: 대상/가격/현재 상태. 푸터: 잔액/페이지/뒤로. 상점의 시세 시간은 필요한 화면에만 표시.
- 아이콘·한글 이름·가격을 하나의 카드에 묶는다. 금액을 월드 위에 흩어 보이게 하거나 격자 밖으로 밀리지 않게 한다.
- 중요 정보는 상시 표시하고 툴팁은 자세한 효과/조작 보조에 사용한다. 긴 이름이나 잔액은 잘라서 금액을 모호하게 만들지 않는다.
- 숫자와 도구 이름은 실제 상태에서 렌더링한다. 배경 PNG에 예시 잔액/옵션을 고정 인쇄하지 않는다.

## 5. 램프 개선 화면 — 자체 제안

### L01 램프 상점 (원본 카드 구조 우선)

```text
램프 상점                                     닫기
────────────────────────────────────────────────
[램프 아이콘]  생활 도구 전용 램프
 보유 N개      생활 도구에 무작위 능력을 부여합니다
               [ 구매 · 단가 YD ]

잔액 N YD                       1/1    [램프 사용]
```

NPC 상호작용으로 진입. 일반 유저에게 명령어 입력을 안내하지 않는다. 단가와 보유량을 바로 표시한다. 원본에서 확인한 1개/Shift+64개 조작을 채택할 경우 **64개 총액을 구매 전에 안내**하고 잔액·보관 한도를 확인한다. 숫자 지갑을 사용하며 돈 아이템 소지를 요구하지 않는다.

### L02 램프 적용 (원본 복제라고 부르지 않는 편의 화면)

```text
생활 램프                               [뒤로]
[대상 도구] 도구 이름
현재 능력   능력 이름 / 실제 수치
──────────────────────────────────────────────
무작위 능력으로 교체됩니다. 기존 능력은 사라집니다.
사용 램프 1개                      보유 N개
[가능한 능력 보기]                  [1회 적용]
```

옵션 도감은 별도 화면으로 분리한다. 확률 미확정 상태에서 같은 크기의 카드만으로 균등 확률을 암시하지 않는다. 처리 후에는 같은 위치에 이전/새 옵션·남은 램프를 보여주고 재시도는 별도 클릭으로 한다. 적용 대상의 교체/소멸, 중복 클릭, 재고 부족 시 무소모 실패와 사유를 표시한다. 빈손일 때 구매는 가능하되 적용은 비활성화한다.

## 6. 토지 UI — 원본 화면 미확보, 자체 제안

### T01 토지 선택

```text
토지                                      보유 n / 최대 n
─────────────────────────────────────────────────────
[주변 청크 지도]          선택한 땅
[현재 위치 + 선택 강조]   월드 / 청크 X, Z
                         상태: 구매 가능 / 내 땅 / 타인 소유
[범례: 내 땅/타인/불가]   가격 N YD · 구매 후 잔액 N YD
                         이용권: 보유 / 필요
[경계 확인] [내 위치]     [구매 내용 확인]
```

지도 크기는 구현 검증 후 확정한다. **현재 9×5를 유지할지 상세 패널용으로 줄일지는 슬롯 배치 계약으로 결정**하며 5×5를 원본 규격이라고 주장하지 않는다. 선택 상태와 현재 위치를 다른 표식으로 표시하고, 범례는 색+문자를 함께 사용한다. 필지 클릭은 선택만 하고 즉시 결제하지 않는다.

### T02 구매 확인

필지 월드·청크·블록 범위, 가격, 현재/구매 후 잔액, 이용권 소모 여부, 구매 후 보유 수를 한 카드에 표시. `구매 확정`과 `돌아가기`만 제공한다. 구매 직전 소유자·가격·한도·권한·이용권을 재검증하고 바뀌면 다시 확인받는다. 땅 선점 실패는 결제하지 않는다. 성공 후 `경계 보기 / 농장 관리`로 연결한다.

### T03 내 농장 관리

내 땅 목록, 멤버 권한, 경계 표시, 자동 심기, 발자국/서리 기록은 관리 화면으로 이동한다. 램프 구매와 도감은 토지 지도 하단을 차지하지 않게 별도 경로로 제공한다. NPC·메뉴 버튼으로 완주 가능하게 하고 상점 명령어는 관리자용으로 제한한다.

## 7. 구현 제약과 완료 조건

현재 Paper+리소스팩의 인벤토리 기반 화면에서 원본의 자유 배치·투명도·HUD 상호작용을 그대로 지원한다고 가정하지 않는다. 폰트 배경은 시각 요소이며 임의 위치가 자동으로 클릭 가능한 버튼이 되지 않는다.

1. 렌더러와 클릭 핸들러가 하나의 슬롯 배치 정의를 공유한다. 넓은 버튼의 모든 포함 슬롯은 같은 행동을 수행한다.
2. 생성기 원본·텍스처·팩 버전을 함께 변경하되, Claude 작업 중 팩 생성/서버 재시작을 중복 실행하지 않는다.
3. GUI scale 2/3/4, 1280×720·1920×1080에서 실제 인게임 캡처를 남긴다. 그림판/웹 시안만으로 완료 처리하지 않는다.
4. 한글, 큰 금액, 보유 0개, 긴 도구 이름, 현재 옵션 없음, 돈 부족, 팩 미적용 상태를 확인한다.
5. 화면의 가격·재고·옵션과 서버 상태가 일치하며 메뉴 장식 아이템은 꺼낼 수 없다.
6. 팩 거절/실패 시 기본 인벤토리 fallback에서도 동일한 정보·거래 확인·권한을 제공한다.
7. 초보자가 명령어 없이 NPC→구매→적용, 토지 선택→구매 확인→경계 확인을 끝낼 수 있어야 한다.

## 8. Claude 작업 순서

- **P0:** 이 문서의 근거 구분 확인. 기존 목재/양피지 시안으로 되돌리지 않기. 원본 램프 영상 27:20~28:40 직접 참고.
- **P1:** 램프 상점 단일 카드와 사용 화면 분리. 구매 파란 버튼·상시 가격·실제 보유량 우선.
- **P1:** 토지 선택/구매 확인/농장 관리 분리. 지도에서 선택한 필지와 비용을 명확히 하기.
- **P2:** 공통 배경·버튼·타이포·상태 표현 통합 후 해상도별 인게임 검수.
- **추가 원본 조사:** 토지 화면이 등장하는 방송 장면을 확보하면 영상 URL·시각·확인 요소를 이 문서에 추가하고 T01~T03 제안을 재검토. 현 단계에서 원본과 동일하다고 보고하지 않기.

기존 [경제 정책](../economy/ORIGINAL-TRANSACTIONS.md)의 계좌 지갑과 사용자 요구를 유지한다. 원본 영상에서 물리 아이템이 보인다는 이유로 돈 아이템 필수 정책을 다시 도입하지 않는다. 시세도 원본 설명과 별개로 사용자의 ‘무작위 변동 + 대량 판매 다음 회차 하락’ 요구를 유지한다.
