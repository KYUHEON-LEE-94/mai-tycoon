# UI · 건축 상점 · 작물 · 시세 요청 및 구현 기록

작성 기준: 2026-10-31. 방송용 원본 띵타이쿤이 참고 대상입니다.
이 문서는 이번 대화의 요청·구현 결정·추가 제안·확인 범위를 모읍니다. 원본에서 확인하지 못한 수치를 원본 규칙으로 표기하지 않습니다.

## 사용자 요청

- 기존 기본 인벤토리 UI를 개선하고, 제공한 원본 광물 상점 이미지와 최대한 비슷하게 만들기.
- 건축 자재를 파는 별도 상점 추가, 향후 유용한 기능 제안.
- 모든 결정과 변경 사항을 MD에 기록하기.
- 커스텀 작물 디자인 개선 및 종류 확대.
- 다양한 작물을 재배하도록 매 회차 시세를 완전 무작위로 추첨하기.
- 한 작물이 많이 팔리면 다음 재조정 때 가격을 낮추기.
- 일반 유저는 NPC로 상점을 사용하고, 상점 명령어는 관리자만 사용하기.
- 다른 사람도 쉽게 설치하도록 플러그인·리소스팩·설치 안내를 함께 배포하기.
- 같은 폴더에서 진행되는 클로드 작업과 기존 농사 기능을 보존하기.

## UI와 이용 흐름

원본 이미지의 어두운 배경, 금색 선, 2열×4행 상품 카드, 상품명·보유량·가격, 붉은 거래 문구, 하단 잔액과 페이지를 반영했습니다.
클라이언트 모드 없이 기본 54칸 인벤토리에 맞추므로 카드 크기와 여백은 원본과 다릅니다. 배경은 불투명이며 원본의 반투명 화면을 그대로 재현한 것은 아닙니다.
배경 글리프는 44×32 논리 픽셀 타일로 분할해 클라이언트 폰트 아틀라스 크기에 맞춥니다.
리소스팩을 거절하거나 받지 못하면 기본 아이템 GUI로 같은 기능을 제공합니다.
상점 하단 시세 시간은 **다음 변경 예정 시각(HH:mm)**입니다. 초 단위 카운트다운이 아닙니다.
씨앗과 건축 상점은 고정 가격 안내를 표시합니다.

| 이용자 | 상점 진입 |
|---|---|
| 일반 유저 | 작물 상인 / 씨앗 상인 / 광장 남서쪽 건축 자재 상인 우클릭 |
| 관리자 | 같은 NPC + `/tycoon cropshop`, `/tycoon seedshop`, `/tycoon buildshop` |

명령어 직접 입력도 `maitycoon.admin`으로 차단하며, 일반 유저의 도움말·자동 완성에서는 숨깁니다. 명령어 별칭 `/타이쿤`도 같은 검사를 거칩니다.
조회·도감·토지 등 기존 비상점 명령어의 권한은 이번 요청에서 바꾸지 않습니다.

## 건축 자재 상점

목재 8종, 석재 8종, 장식 8종, 총 24종입니다. 목재/석재/장식 탭과 전체 탭을 제공합니다.
좌클릭은 선택 수량 1/8/16/32/64개, 우클릭은 한 묶음입니다.
잔액·보관 공간·거래 제한을 검사하고 기존 거래 기록을 이용합니다.
기본 자재와 가격은 `config.yml`의 `building-shop`에 있으며 개발용 가격입니다.
상인은 추가했으며 별도 대형 건물을 새로 짓거나 기존 월드를 평탄화하지 않습니다.
자세한 품목 관리와 후속 제안은 [건축 상점 문서](building-shop.md)를 참고하세요.

## 새 시세 규칙

### 독립 무작위 추첨

기본 주기 10분, 최저 50%, 최고 180%입니다.
각 작물은 매 회차 **50~180의 정수 퍼센트에서 균등 추첨**합니다. 이전 시세에 따른 상승/하락 폭이나 기준가 회귀는 없습니다.
YD는 `max(1, round(기준가 × 퍼센트 / 100))`입니다. 반올림 때문에 최종 YD 값 자체가 균등 분포인 것은 아닙니다.
`Rule.swing`과 설정의 `swing`은 이전 설정 호환을 위해 남아 있지만 새 추첨에는 사용하지 않습니다.

### 많이 팔린 품목의 다음 회차 하락

- 판매량은 **서버 전체, 품목별, 현재 회차**로 합산합니다. 단품·우클릭 전량·모두 판매 모두 포함합니다.
- 구매, 판매 취소, 실패한 사전 검사, 판매 확인 견적만 열기는 판매량에 포함하지 않습니다.
- 기본 256개마다 하락 압력 10%, 최대 60%입니다.
- `압력 = min(60, floor(이번 회차 판매량 / 256) × 10)`.
- 무작위 추첨 퍼센트에 `(100 - 압력) / 100`을 곱한 후 최저가를 적용합니다.
- 압력이 있으면 **직전 가격에서 압력 비율만큼, 최소 1 YD 내려간 가격**을 상한으로도 적용합니다. 따라서 추첨값이 높아도 과잉 판매 품목은 다음 가격이 내려갑니다.
- 이미 최저가이면 더 내려갈 수 없습니다. 판매량이 많아도 최저가는 지킵니다.
- 예: 직전 100 YD, 512개 판매 → 20% 압력 → 다음 가격은 최대 80 YD. 최저가가 더 높으면 최저가 적용.
- 변경 후 판매량은 0으로 초기화합니다. 다음 회차에는 다시 새 판매량만 반영합니다. 영구 페널티가 아닙니다.
- 다른 작물의 판매량은 해당 작물의 추첨에 영향을 주지 않습니다.

**완전 무작위 부분은 기본 추첨이며, 최종 가격에는 사용자 요청인 공급량 보정이 적용됩니다.**
이 규칙이 모든 작물의 재배 비율을 같게 보장하지는 않습니다. 성장 시간·수확량·씨앗 가격을 포함해 실제 플레이 데이터를 보고 조정해야 합니다.

설정: `market.volume-threshold`, `market.pressure-per-batch`, `market.max-pressure`.
판매량·최근 적용 압력·가격·다음 갱신 시각은 `market.yml`에 저장합니다. 파일은 임시 파일 작성 후 교체합니다.
서버 재시작으로 판매량이 사라지거나 다음 갱신 시간이 매번 10분 뒤로 밀리지 않게 했습니다. 갱신 시각이 지난 서버는 시작 후 다음 검사에서 한 번 갱신합니다.
판매 아이템 설명에 현재 서버 판매량과 예정 하락 압력을 표시합니다.
저장 도중 오류가 나면 거래 기록을 남겨 관리자 확인 대상으로 유지합니다.

## 추가하면 좋은 기능 (미구현 제안)

1. **일일 납품 게시판**: 다양한 작물의 제한 수량 주문과 사전 보상 표시. 일일 총 보상 상한을 둡니다.
2. **농장 상태판**: 성장 중/수확 가능 작물, 다음 시세 시각을 한 화면에서 확인합니다.
3. **창고 분류·판매 보호**: 씨앗과 건축 자재를 구분하고 판매 제외 보관함을 제공합니다.
4. **건축 설계도**: 창고·온실 미리보기, 필요 자재와 비용 확인, 소유한 땅에서 최종 확인 후 건축합니다.
5. **협동 농장 권한 보강**: 기존 작업자 권한을 수확/파종/건축별로 세분화하고 기록을 제공합니다.

추천 순서: 납품 게시판 → 농장 상태판 → 창고 → 설계도.

## 검증과 배포

- 시세 독립 추첨, 범위, 서버 판매량 누적, 실가격 하락, 최저가, 품목별 격리, 회차 초기화, 판매량 복원, 큰 판매량 처리 자동 테스트.
- 설정된 12종 모두 수확물·씨앗·3단계 PNG/모델/선택자·상점 이름이 존재하는지 테스트.
- 건축 자재 24종, 가격, 상점 이름·분류 수 검사.
- 배경 타일 크기와 클릭 영역 겹침 검사.
- 기존 config.yml에 새 기본 설정/작물 항목을 합쳐 저장하되 기존 사용자 설정 값은 보존합니다. 이전 설정 업그레이드도 자동 테스트합니다.
- `./scripts/package.sh`로 테스트 후 최신 버전의 배포 ZIP을 생성합니다. JAR 내부에 리소스팩이 포함됩니다.
- 게임에서의 실제 화면·비관리자 클릭 검증 여부와 최종 서버 적용 상태는 작업 완료 시 아래에 기록합니다.

- 자동 테스트 **47개 통과**, 실패/오류/건너뜀 0개.
