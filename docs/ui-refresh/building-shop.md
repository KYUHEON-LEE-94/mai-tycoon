# 건축 자재 상점

일반 유저는 광장 남서쪽 건축 자재 상인을 우클릭해 엽니다.
`/tycoon buildshop`은 `maitycoon.admin` 권한이 있는 관리자만 사용할 수 있습니다.
목재 8종, 석재 8종, 장식 8종을 고정 골드 가격에 구매합니다.
좌클릭은 선택 수량(1/8/16/32/64), 우클릭은 한 묶음(64개)을 구매합니다.
잔액과 인벤토리 공간을 확인한 후 기존 거래 기록/저장 절차로 처리합니다.
리소스팩을 거절하면 같은 기능의 기본 인벤토리 UI가 표시됩니다.

`config.yml`의 `building-shop`에서 개당 가격을 변경하고 재시작합니다.
기존 서버는 새 기본 항목을 config.yml에 자동 보충하며 기존 설정 값은 보존합니다. 설정 삭제가 필요 없습니다.
품목/분류 변경 시 그림 리소스의 이름/탭도 함께 수정해야 합니다.
원본 서버의 가격표를 복제한 것이 아니라 개발용 균형 값입니다.

## 다음 기능 제안 (아직 구현하지 않음)

1. **농산물 납품 게시판**: 일일 수량 제한 주문과 보상 미리보기. 시세가 낮을 때에도 농사 목표를 제공합니다. 인플레이션 방지를 위해 일일 총 보상에 한도를 둡니다.
2. **건축 미리보기와 자재 목록**: 작은 창고·온실 설계도를 골라 필요한 자재와 비용을 확인합니다. 배치는 소유한 땅에서만, 최종 확인 후 실행합니다.
3. **농장 상태판**: 재배 중인 작물, 수확 가능 수량, 다음 시세 변경 시간을 한곳에 표시합니다.
4. **창고 정리와 판매 보호**: 씨앗·건축용 자재를 쉽게 분류하고 판매 제외 보관함을 둡니다.
5. **공동 농장 권한**: 친구별 수확/심기/건축 권한과 변경 기록. 현재 토지 보호를 바탕으로 확장합니다.

추천 구현 순서는 납품 게시판 → 농장 상태판 → 창고 → 설계도입니다.
