# Mai Tycoon 클라이언트 통신 규격

버전: **1.2** (major 1, minor 2)

서버(Paper 플러그인)와 클라이언트(Fabric 모드)는 이 문서와 `vectors/`의 바이트로만 맞춘다. 두 쪽은 코드를 공유하지 않는다. 각 쪽 테스트가 같은 `vectors/*.hex`를 해석하고 다시 만들어 바이트가 같은지 확인한다. 시험 데이터는 `make_vectors.py`가 이 문서만 보고 따로 만든다.

## 채널

| 채널 | 방향 | 내용 |
|---|---|---|
| `maitycoon:hello` | 클라이언트 → 서버 | 접속 후 모드 버전과 지원 기능 |
| `maitycoon:hello_ack` | 서버 → 클라이언트 | 호환 여부와 허용 기능 |
| `maitycoon:map_request` | 클라이언트 → 서버 | 전체 지도 요청 |
| `maitycoon:map` | 서버 → 클라이언트 | 지도 응답 |
| `maitycoon:shop` | 서버 → 클라이언트 | 상점 화면 내용(열기 또는 갱신) |
| `maitycoon:shop_request` | 클라이언트 → 서버 | 구매·판매·갱신·닫기 |
| `maitycoon:shop_result` | 서버 → 클라이언트 | 요청 결과. 이어서 `shop` 갱신이 온다 |

클라이언트는 서버가 `maitycoon:hello` 채널을 등록했다고 알린 뒤에 `hello`를 보낸다. 등록하지 않은 서버는 Mai Tycoon 서버가 아니다.

## 자료형

- 모든 정수는 big-endian이다. `u8`, `u16`은 부호 없음, `i32`는 부호 있음이다.
- `i64`는 부호 있는 8바이트다.
- `str`은 `u16` 바이트 길이 뒤에 UTF-8 바이트가 온다. 최대 256바이트다.
- 목록은 `u8` 개수 뒤에 항목이 온다. 최대 32개다.
- 메시지 끝에 남는 바이트가 있거나 모자라면 잘못된 메시지다. 받는 쪽은 버리고, 서버는 그 요청에 아무것도 하지 않는다.

## 메시지

### hello

| 필드 | 형 |
|---|---|
| major | u16 |
| minor | u16 |
| modVersion | str |
| features | 목록(str) |

### hello_ack

| 필드 | 형 | 설명 |
|---|---|---|
| status | u8 | 0 호환, 1 클라이언트가 오래됨, 2 서버가 오래됨 |
| major | u16 | 서버 규격 |
| minor | u16 | 서버 규격 |
| message | str | 플레이어에게 보여 줄 문장. 호환이면 빈 문자열 |
| features | 목록(str) | 이 세션에서 쓸 수 있는 기능 |

major가 같으면 호환이다. 서버는 클라이언트가 보낸 minor가 자기보다 낮으면 그 minor의 메시지 형식으로 보내고, 클라이언트는 `hello_ack`의 minor로 형식을 고른다. 지금 기능은 `full_map` 하나다.

| 버전 | 변경 |
|---|---|
| 1.0 | 최초. 지도 한 칸 = 1청크 |
| 1.1 | `map`에 `cellBlocks` 추가(서버는 8을 보낸다). 1.0 클라이언트에는 1.0 형식 유지 |
| 1.2 | 상점 메시지 3종과 기능 `shop` 추가. `shop` 기능을 낸 클라이언트에게는 NPC가 상자 화면 대신 `shop`을 보낸다 | 응답에는 클라이언트가 제안하고 서버도 지원하는 기능만 포함한다. 지도 요청은 `full_map`을 협의한 세션만 처리한다. 클라이언트도 응답 major와 기능을 확인하고, 응답이 약 5초(100 클라이언트 틱) 동안 없으면 재접속 안내를 표시한다.

### map_request

| 필드 | 형 |
|---|---|
| requestId | i32 |

서버는 같은 플레이어의 요청을 0.4초에 한 번만 처리한다. 그보다 빠른 요청은 응답 없이 버린다.

### map

| 필드 | 형 | 설명 |
|---|---|---|
| requestId | i32 | 요청의 번호 |
| originX | i32 | 0번 칸의 칸 좌표 X (블록 X ÷ cellBlocks, 내림) |
| originZ | i32 | 0번 칸의 칸 좌표 Z |
| width | u16 | 1~128 |
| height | u16 | 1~128 |
| cellBlocks | u8 | 한 칸의 블록 수. 1.1부터. 상대가 1.0이면 이 필드를 빼고 16으로 본다 |
| colors | width×height × i32 | 북서쪽부터 행 우선. 0xRRGGBB, -1은 기록 없음 |
| overlays | width×height × u8 | 0 없음, 1 내 땅, 2 남의 땅, 3 마을 |
| selfX | i32 | 요청한 플레이어의 블록 X |
| selfZ | i32 | 요청한 플레이어의 블록 Z |
| players | 목록 | 같은 월드의 다른 플레이어 |
| └ name | str | |
| └ x | i32 | 블록 X |
| └ z | i32 | 블록 Z |

지도는 공개 범위 정책을 따른다. 같은 월드의 플레이어는 거리와 상관없이 서로의 위치와 이름을 보고, 관전자와 서로 볼 수 없는 플레이어는 빠진다. 땅은 소유자 이름 없이 내 땅인지 남의 땅인지만 보낸다.

### shop_request (클라이언트 → 서버)

| 필드 | 형 | 설명 |
|---|---|---|
| requestId | i32 | |
| kind | u8 | 열려 있는 상점과 같아야 한다 |
| action | u8 | 0 구매, 1 판매, 2 모두 판매, 3 갱신, 4 닫기 |
| item | str | 구매·판매 대상. 모두 판매·갱신·닫기는 빈 문자열 |
| amount | i32 | 수량. 모두 판매는 0 |
| revision | i32 | 판매는 화면의 revision. 다르면 서버가 거절하고 새 화면을 보낸다 |

서버는 요청마다 수량·잔액·공간·회차를 다시 확인한다. 클라이언트가 보낸 가격은 없다.

## 필수 운영

`client.required: true`이면 서버는 접속 후 `client.wait-seconds` 안에 호환되는 `hello`를 받지 못한 플레이어를 설치 안내와 함께 내보낸다. 기다리는 동안에는 이동, 상호작용, 인벤토리, 명령어, 블록 설치와 파괴, 아이템 버리기를 막는다. 비호환 `hello`를 받으면 바로 업데이트 안내와 함께 내보낸다. `false`(기본)이면 막지 않고, 비호환 클라이언트에는 `hello_ack`로 안내만 한다.
